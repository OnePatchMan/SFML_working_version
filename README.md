# Fighting Combo Game

Двумерный экшен-платформер / комбо-файтинг с глубокой механикой рукопашного боя, древковым оружием, умным искусственным интеллектом противников, динамической системой крови и процедурно связанными комнатами.

Проект разработан на **C++17/20** с использованием графической библиотеки **SFML 3** и аудиодвижка **miniaudio**.

---

## О чем игра (Геймплей)

**Fighting Combo Game** объединяет динамику классических 2D-платформеров со сложной и отзывчивой боевой системой в духе соревновательных файтингов (*Guilty Gear*, *Tekken*, *Super Smash Bros.*). 

### 1. Двухрежимная боевая система: Булава vs Рукопашный бой

Персонаж начинает игру с массивной древковой булавой-молотом (**Meat Tenderizer Polearm**):
* **Вооруженный режим (Булава)**:
  * Мощные сокрушительные одиночные удары (`MACE: Heavy Thrust` на ЛКМ, `MACE: Overhead Smash` на ПКМ) с колоссальным отталкиванием и уроном.
  * Булаву можно метнуть в любое из **8 направлений** (клавиша `R`, клик колесика мыши `MMB` или скролл).
  * **Физика броска**: булава летит стабильно как копье без вращения. Скорость и урон полета напрямую масштабируются от импульса движения игрока (бросок с места — $550\text{ px/s}$, бросок на бегу или в рывке — до $1200+\text{ px/s}$).
  * Попадание на высокой скорости пробивает противника и вызывает фатальное расплескивание крови.
  * Булаву можно подобрать с земли на ту же кнопку (`R` / `MMB`), вернувшись в вооруженный режим.
* **Безоружный режим (Рукопашный бой)**:
  * Включается автоматически, когда булава брошена.
  * Открывает доступ к разветвленному дереву направленных боевых комбинаций:
    * **Наземные лаунчеры (Launchers)**: подбрасывание врага по диагонали (`1-f2-d1`) или вертикально вверх (`2-1-db1`, `1-1-2`) для перехода в воздушную серию.
    * **Воздушное жонглирование (Air Juggle)**: комбо-серии в воздухе (`a1`, `a2`), горизонтальный отброс (`a1-a2`).
    * **Воздушный слэм (Ground Bounce)**: сокрушительный удар об землю с отскоком (`a1-adw2`, `a1-a1-adw2`).
    * **Захваты (Grab & Throw)**: захват врага и бросок назад через спину с разворотом персонажа (`1-1-b2`).
    * **Рывки и сметки (Sweep / Dash Smash)**: подсечка ног и горизонтальный смэш (`1-2-df2`).

### 2. Защита, уклонение и парирование
* **Блок (`F` / `E`)**: выставляет защитный энергетический барьер, поглощающий 80% входящего урона. Серия ударов в блок заполняет шкалу и может вызвать блок-стан.
* **Рывок и уклонение (Dodge Roll & Spot Dodge)**:
  * Рывок в движении (`Shift + A/D`): быстрый перекат сквозь врагов с кадрами полной неуязвимости (i-frames).
  * Спот-додж на месте (`Shift` без направления): уклонение от атак без смещения позиции.
* **Стойка контратаки и парирование (`Q`)**: переход в защитную стойку. Точно подгаданное парирование активирует **★ CRITICAL COUNTER ★** с нанесением критического урона и оглушением врага.

### 3. Честный соревновательный баланс
* **Анти-спам система**: повтор одной и той же связки комбо в течение 2.5 секунд приводит к стан-локу самого атакующего. Игра поощряет разнообразие приемов.
* **Whiff Stunlock**: промах мимо цели задерживает персонажа в фазе восстановления, делая его уязвимым для контратаки.
* **Damage Scaling (Proration)**: с каждым новым ударом в длинной серии урон и хитстан постепенно снижаются (до 30%), предотвращая бесконечные оглушения.

### 4. Интеллект врагов и архетипы
Противники адаптируются к ситуации и делятся на 3 архетипа:
1. **Обычный боец (`NORMAL`, серый)**: сбалансированный противник, патрулирует платформы без падения в пропасти, проводит комбо-стартеры.
2. **Танк (`TANK`, красный, увеличенный размер)**: 110 HP, тяжелая броня, повышенное сопротивление отталкиванию и подбрасыванию, мощные медленные атаки.
3. **Дуэлянт (`DUELIST`, фиолетовый)**: быстрый ловкач с продвинутым ИИ, способный совершать уклонения, использовать Spot Dodge, блокировать комбо игрока и контратаковать.

### 5. Режимы игры, карты комнат и редактор
* **10 процедурно связанных комнат**: перемещение между комнатами через двери на границах экрана.
* **Встроенный редактор карт (`F6`)**: позволяет прямо на лету переключаться в режим редактирования уровня, ставить и стирать блоки, двери, спавны игрока и врагов с автосохранением в форматы `.kv`, `.txt` и `.png`.
* **Горячая перезагрузка (`F5`)**: мгновенная перезагрузка конфигурационных файлов баланса (`assets/config/*.kv`), звуков и комнат без перезапуска игры.

## Управление

### Передвижение
| Клавиша | Действие |
| :--- | :--- |
| `A` / `D` или `←` / `→` | Движение влево / вправо |
| `Space` (Пробел) | Прыжок (переменная высота, Coyote Time, Jump Buffer) |
| `Shift` + `A` / `D` | Перекат / Дэш (Dodge Roll) с кадрами неуязвимости |
| `Shift` (на месте) | Уклонение на месте (Spot Dodge) |

### Боевая система
| Клавиша / Кнопка мыши | Действие |
| :--- | :--- |
| `ЛКМ` (Mouse 1) | **Булава**: Силовой колющий выпад (`Heavy Thrust`)<br>**Без оружия**: Быстрый легкий удар рукой (`Light Attack 1`) |
| `ПКМ` (Mouse 2) | **Булава**: Сокрушительный удар сверху (`Overhead Smash`)<br>**Без оружия**: Тяжелый удар ногой (`Heavy Attack 2`) |
| `Колесико мыши (клик)` / `Скролл` / `R` | **Бросок булавы** по 8 направлениям / **Подбор булавы** с земли |
| `F` или `E` *(зажать)* | **Блок** щитом (поглощение 80% урона) |
| `Q` | **Стойка парирования** / Парирование удара (Counter Stance) |

### Направленные комбо-удары (в безоружном режиме)
| Комбинация | Название | Эффект |
| :--- | :--- | :--- |
| `1` $\rightarrow$ `1` $\rightarrow$ `1` | Тройная легкая серия | Базовое нанесение урона и отталкивание |
| `1` $\rightarrow$ `f+2` $\rightarrow$ `d+1` | Диагональный подброс | Запуск врага по диагонали в воздух |
| `1` $\rightarrow$ `1` $\rightarrow$ `b+2` | Захват и бросок назад | Хватает врага, перебрасывает за спину и разворачивает героя |
| `2` $\rightarrow$ `1` $\rightarrow$ `db+1` | Обратный свип-лаунчер | Сбивает с ног и вертикально запускает врага вверх |
| `1` $\rightarrow$ `1` $\rightarrow$ `2` | Быстрый лаунчер | Мгновенный вертикальный запуск для воздушной серии |
| `Воздух`: `1` $\rightarrow$ `1` $\rightarrow$ `adw+2` | Двойной воздушный слэм | Вбивает противника в землю с отскоком (Ground Bounce) |
| `Воздух`: `1` $\rightarrow$ `2` | Горизонтальный пуш | Отбрасывает врага по горизонтали в воздухе |
| `1` $\rightarrow$ `2` $\rightarrow$ `df+2` | Горизонтальный смэш | Мощный удар в рывке вперед |

### Служебные и горячие клавиши
| Клавиша | Назначение |
| :--- | :--- |
| `Tab` | Переключение режима врагов: **Умный ИИ** $\leftrightarrow$ **Тренировочный манекен** |
| `Y` | Смена архетипа врагов по кругу: `NORMAL` $\rightarrow$ `TANK` $\rightarrow$ `DUELIST` |
| `Backspace` | Сброс (ресет) позиций игрока, противников и боевого состояния |
| `PageUp` / `PageDown` | Быстрое переключение комнат (`room_1` $\dots$ `room_10`) |
| `F5` | Горячая перезагрузка всех конфигураций (`.kv`), звуков и комнат |
| `F6` | Включение / выключение встроенного редактора карт |
| `Esc` | Пауза / Меню выхода |

## Требования к системе

* **ОС**: Linux (Ubuntu 22.04+, Debian 12+, Arch, Fedora) или Windows (с компилятором MSVC / MinGW).
* **Компилятор**: C++17 или выше (GCC 11+, Clang 14+).
* **Система сборки**: CMake 3.16+.
* **Библиотеки**: **SFML 3** (компоненты `Graphics`, `Window`, `System`, `Audio`).

## Установка зависимостей (Ubuntu / Debian)

```bash
sudo apt update
sudo apt install -y build-essential cmake libsfml-dev libgl1-mesa-dev libx11-dev
```

> [!NOTE]
> Проект ориентирован на **SFML 3**. Если в системных пакетах дистрибутива установлена SFML 2.x, убедитесь, что библиотека SFML 3 собрана или доступна через CMake (`find_package(SFML 3 ...)`).

## Сборка и запуск игры

### 1. Сборка проекта через CMake

```bash
# Клонирование или переход в папку проекта:
cd /home/dagai/Projects/SFML_working_version

# Создание каталога сборки:
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Компиляция:
cmake --build build -j$(nproc)
```

### 2. Запуск основной игры

```bash
./build/Test
```

### 3. Запуск автономного редактора комнат

```bash
./build/MapEditor
```

### 4. Запуск автоматических тестов боевой системы

Проект оснащен набором из **50 комплексных тестов**, проверяющих комбо, физику броска булавы, лаунчеры, ИИ, масштабирование урона и брызги крови:

```bash
# Обычный запуск тестов:
./build/test_directional_combos

# Или запуск в безголовом окружении (CI / headless сервер):
xvfb-run -a ./build/test_directional_combos
```
