### 4. Кастомная логика триггеров арены (Arena Trigger Custom Logic)
- [x] **4 режима активации триггеров**:
  1. **Касание (`Touch`)** — непосредственное пересечение хитбокса триггера.
  2. **Пересечение X (`Cross X`)** — пересечение координаты X триггера по всей высоте арены.
  3. **Пересечение Y (`Cross Y`)** — пересечение координаты Y триггера по всей ширине арены.
  4. **В поле зрения (`In View`)** — срабатывание, как только триггер попадает в область видимости камеры.
- [x] **Кастомные события и действия триггера**:
  - Полная невидимость логических триггеров в игре при цветной визуализации в редакторе карт.
  - Динамический спавн барьерных блоков (`TileId::BARRIER = 9`) по произвольным координатам с авто-очисткой при победе.
  - Спавн любых врагов (Обычный, Танк, Дуэлянт, Манекен, Босс 1) по координатам.
  - Фиксация камеры на произвольных координатах точки `(x, y)` или конкретном враге/боссе.
  - Автоматический чистый сброс камеры (возврат на игрока, 1280x720) и перезапуск музыки при гибели игрока и победе над боссом.
  - Динамический переход на саундтрек босса `Boss1.mp3` без сброса фоновой музыкой.
