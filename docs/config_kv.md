# Конфигурационные файлы KeyValues (KV Format Specification)

Документ описывает синтаксис и структуру файлов конфигурации формата Valve KeyValues (`.kv`), используемых в проекте для настройки баланса, характеристик сущностей и разметки комнат.

---

## 1. Синтаксис формата KeyValues

Конфигурационные файлы состоят из пар ключ-значение и вложенных секций:
```kv
// Однострочный комментарий
"SectionName"
{
    "key1"      "value1"
    "key2"      "value2"
    
    "SubSection"
    {
        "item_0"    "10 20 1"
    }
}
```

---

## 2. Спецификация конфигураций

### 2.1. `assets/config/combat_balance.kv` (Таблица баланса боя)
Содержит две главные таблицы:
1. `"Attacks"` — параметры базовых ударов:
   * `damage`: базовый урон.
   * `hitstun`: длительность стана цели при попадании.
   * `blockstun`: длительность стана цели при попадании в блок.
   * `whiffstun`: штрафная длительность стана при промахе по воздуху.
   * `knockback_x`, `knockback_y`: вектор отталкивания цели.
2. `"Combos"` — параметры комбо-цепочек и финишеров:
   * `combo_key`: строковый ключ последовательности (например `"1f2d1"`).
   * `cooldown`: длительность независимого кулдауна комбо (по умолчанию `2.5` секунды).
   * `ground_bounce`: флаг отскока от земли (`1` или `0`).
   * `bounce_vy`: вертикальная скорость отскока.

### 2.2. `assets/config/enemy.kv` (Баланс архетипов врагов)
Определяет физические и поведенческие характеристики трех архетипов:
* `"Normal"`:
  * `hp`: здоровье (по умолчанию `45`).
  * `scale`: масштаб спрайта (`1.0`).
  * `speed`: скорость бега (`225.0`).
  * `armor`: тип брони (`light`).
  * `can_counter`: возможность контратаки (`0`).
* `"Tank"`:
  * `hp`: здоровье (по умолчанию `110`).
  * `scale`: масштаб спрайта (`1.5`).
  * `speed`: скорость бега (`160.0`).
  * `armor`: тип брони (`heavy`, снижает длительность стана и импульс отталкивания в 2 раза).
  * `can_counter`: возможность контратаки (`0`).
* `"Duelist"`:
  * `hp`: здоровье (по умолчанию `65`).
  * `scale`: масштаб спрайта (`1.0`).
  * `speed`: скорость бега (`330.0`).
  * `can_counter`: возможность парирования и контратаки (`1`).
  * `aggressiveness`: агрессивность наступления (`0.65`).
  * `intelligence`: интеллект выбора комбо и уклонений (`0.85`).

### 2.3. `assets/config/player.kv` (Параметры игрока)
* `max_hp`: максимальное здоровье игрока (`100`).
* `move_speed`: скорость перемещения (`300.0`).
* `jump_power`: сила прыжка (`580.0`).
* `dash_speed`: скорость рывка (`520.0`).
* `dash_duration`: длительность кадров неуязвимости (`0.22`).
* `block_damage_reduction`: процент снижения урона блоком (`0.80`).

### 2.4. `assets/maps/room_*.kv` (Координаты комнат и спавнов)
Определяет топологию комнаты:
* `"width"`, `"height"`: размеры карты в тайлах.
* `"player_spawn"`: координаты тайла спавна игрока (`x y`).
* `"Enemies"`: список врагов в формате `"enemy_X" "x y archetype"`, где архетип:
  * `0` — Обычный (`NORMAL`)
  * `1` — Жирный (`TANK`)
  * `2` — Дуэлянт (`DUELIST`)
* `"Doors"`: список дверей перехода в формате `"door_X" "x y targetRoom"`.
* `"Platforms"`: список непрерывных горизонтальных платформ в формате `"plat_X" "x y length"`.
