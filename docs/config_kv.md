# Конфигурационные файлы KeyValues (KV Format Specification)

Документ описывает синтаксис и структуру файлов конфигурации формата Valve KeyValues (`.kv`), используемых в проекте для настройки баланса боя, параметров персонажа, архетипов врагов и боссов, а также разметки комнат, интерактивных дверей и кастомных триггеров.

---

## 1. Синтаксис формата KeyValues

Конфигурационные файлы состоят из пар ключ-значение и вложенных секций:
```kv
// Однострочный комментарий
"SectionName"
{
    "key1"      "value1"
    "key2"      "value2"
    
    "SubSection"
    {
        "item_0"    "10 20 1"
    }
}
```

---

## 2. Спецификация конфигураций

### 2.1. `assets/config/combat_balance.kv` (Таблица баланса боя)
Содержит две главные таблицы:
1. `"Attacks"` — параметры базовых ударов:
   * `damage`: базовый урон.
   * `hitstun`: длительность стана цели при попадании.
   * `blockstun`: длительность стана цели при попадании в блок.
   * `whiffstun`: штрафная длительность стана при промахе по воздуху.
   * `knockback_x`, `knockback_y`: вектор отталкивания цели.
2. `"Combos"` — параметры комбо-цепочек и финишеров:
   * `combo_key`: строковый ключ последовательности (например `"1f2d1"`).
   * `cooldown`: длительность независимого кулдауна комбо (по умолчанию `2.5` секунды).
   * `ground_bounce`: флаг отскока от земли (`1` или `0`).
   * `bounce_vy`: вертикальная скорость отскока.

### 2.2. `assets/config/enemy.kv` (Баланс архетипов врагов и боссов)
Определяет физические и поведенческие характеристики архетипов:
* `"Normal"`:
  * `hp`: 45.
  * `scale`: 1.0.
  * `speed`: 225.0.
  * `armor`: light.
  * `can_counter`: 0.
* `"Tank"`:
  * `hp`: 110.
  * `scale`: 1.5.
  * `speed`: 160.0.
  * `armor`: heavy (снижение стана на 45%, отталкивания на 50%).
  * `can_counter`: 0.
* `"Duelist"`:
  * `hp`: 65.
  * `scale`: 1.0.
  * `speed`: 330.0.
  * `can_counter`: 1 (парирование и контратака).
  * `aggressiveness`: 0.65.
  * `intelligence`: 0.85.
* `"Boss1"`:
  * `hp`: 200.
  * `scale`: 2.0 ($128 \times 96\text{ px}$).
  * `speed`: 200.0.
  * `force_immunity`: 1 (полный иммунитет к отталкиванию и подбросам).
  * `combo_chaining`: 0 (запрет связывания комбо).
  * `combo_cooldown`: 2.0 (пауза между сериями).
  * `can_block`: 0.
  * `can_counter`: 0.
  * `can_dodge`: 0.
  * `solid_collision`: 1 (не проходит сквозь твердые блоки).

### 2.3. `assets/config/player.kv` (Параметры игрока)
* `max_hp`: максимальное здоровье игрока (`100`).
* `move_speed`: скорость перемещения (`300.0`).
* `jump_power`: сила прыжка (`580.0`).
* `dash_speed`: скорость рывка (`520.0`).
* `dash_duration`: длительность кадров неуязвимости (`0.22`).
* `block_damage_reduction`: процент снижения урона блоком (`0.80`).

## 3. Спецификация карт комнат (`assets/maps/room_*.kv`)

Определяет полную геометрию, слои тайлов, интерактивные объекты и кастомную логику триггеров:

### 3.1. Основные параметры
* `"name"`: имя комнаты (например `"room_1"`).
* `"floor_type"`: `"basement"` (черный фон, без окон) или `"normal"` (дневное небо, дневной свет из окон).
* `"width"`, `"height"`: размеры карты в тайлах (80x20).
* `"player_spawn"`: точка старта игрока (`"x y"`).
* `"test_spawn"`: чекпоинт симуляции MapEditor (`"x y"`).

### 3.2. Секция `"Enemies"`
Список врагов: `"enemy_X" "x y type [tag]"`:
* `type`:
  * `0` — Обычный (`NORMAL`, `normal`)
  * `1` — Жирный (`TANK`, `tank`)
  * `2` — Дуэлянт агрессивный (`DUELIST`, `duelist_agg`)
  * `3` — Дуэлянт пассивный (`duelist_pas`)
  * `4` — Манекен (`dummy`)
  * `5` — БОСС 1 (`boss_1`)

### 3.3. Секция `"InteractiveDoors"`
Интерактивные разрушаемые двери:
```kv
"InteractiveDoors"
{
    "door_0"  "4 4 0 0" // x y targetRoom isBroken
}
```

### 3.4. Секция `"Triggers"` (Кастомная логика триггеров)
Задается в формате:
```kv
"Triggers"
{
    "trigger_0"  "x y w h tokens..."
}
```
Поддерживаемые токены:
* `cond:<type>` — условие срабатывания:
  * `cond:touch` — физическое касание триггера.
  * `cond:cross_x` — пересечение X координаты триггера.
  * `cond:cross_y` — пересечение Y координаты триггера.
  * `cond:in_view` — попадание триггера в область экрана камеры.
* `boss:1` — флаг активации боссфайта (показ верхнего HP-бара, смена музыки).
* `bossname:<Name>` — отображаемое имя босса на плашке здоровья.
* `spawne:x y type [id]` — динамический спавн врага заданного типа при активации триггера.
* `spawnb:x y tileId` — динамическое размещение блока/барьера при активации (запечатывание арены).
* `camlock:<mode>` — режим фиксации камеры:
  * `0` — свободная (следует за игроком).
  * `1` — на блоке/точке (`campos:x y`).
  * `2` — на враге по индексу/тегу (`camentag:<tag>`, `camenidx:<idx>`).
  * `3` — между игроком и боссом (Boss/Player midpoint).
* `campos:x y` — мировые координаты фиксации камеры.
* `camsize:w h` — разрешение/зум камеры (1280 720, 1600 900, 1920 1080, 960 540).

### 3.5. Секции слоев `"BackgroundLayer"` и `"TileLayer"`
Содержат по 20 строк (`"row_0"` .. `"row_19"`), разделенных пробелами (80 чисел на строку):
* `"BackgroundLayer"` — нематериальный фоновый слой (кирпичи `08_bg.png = 8`).
* `"TileLayer"` — верхний слой коллизии (стены, платформы, лестницы, барьеры `9`).
