# Редактор карт комнат (Map Editor Guide)

Документ описывает функционал встроенного в игру редактора карт (`[F6]`) и автономного редактора (`MapEditor`), управление, палитру инструментов, размещение врагов по архетипам и настраиваемые двери перехода между комнатами.

---

## 1. Запуск и управление

* **Вход / Выход из встроенного редактора**: Клавиша `[F6]`.
* При выходе из редактора бой возобновляется автоматически с респавном всех врагов на новых точках.
* **Автономный редактор**: Собирается отдельным таргетом `MapEditor` и запускается из корневой директории сборки:
  ```bash
  ./build/MapEditor
  ```

### Горячие клавиши редактора:

| Клавиша | Функция |
|---|---|
| `[1]` | Инструмент: **Платформа / пол** (`=`) |
| `[2]` | Инструмент: **Стена / монолитный блок** (`#`) |
| `[3]` | Инструмент: **Дверь / переход в комнату** (`D`) |
| `[4]` | Инструмент: **Спавн игрока** (`P`, лаймовый маркер) |
| `[5]` | Инструмент: **Спавн обычного врага** (`N`, Normal, серый маркер) |
| `[6]` | Инструмент: **Спавн жирного врага** (`T`, Tank, красный увеличенный маркер $1.5\times$) |
| `[7]` | Инструмент: **Спавн дуэлянта** (`D`, Duelist, фиолетовый маркер) |
| `[8]` | Инструмент: **Ластик** (стереть блок / удалить спавн или дверь) |
| `[ЛКМ]` | Рисование выбранным инструментом |
| `[ПКМ]` | Стирание блока / удаление двери / удаление спавна врага под курсором |
| `[СКМ] / Drag` | Панорамирование камеры по огромной карте |
| `[B]` | Циклическое изменение размера кисти: `1x1`, `2x2`, `3x3`, `5x5` |
| `[ [ ]` / `[ ] ]` | Переключение целевой комнаты двери (1 .. 10) |
| `[PageDown]` / `[PageUp]` | Переход к предыдущей / следующей комнате |
| `[Z]` / `[X]` / `Ctrl+Колесо` | Масштабирование зума камеры (от 40% до 300%) |
| `[Ctrl+S]` / `[F7]` | Сохранение текущей комнаты во всех форматах (`.kv`, `.txt`, `.png`) |
| `[F5]` | Горячая перезагрузка текстур тайлов из папки `assets/tiles/` |

## 2. Размещение врагов по архетипам

В редакторе карт реализована поддержка произвольного количества точек спавна врагов с индивидуальным выбором архетипа:

1. **Обычный враг (`[5]`, `Normal`)**:
   * Отображается серым контуром с бейджем `Norm#X`.
   * На миникарте отображается серой точкой.
2. **Жирный враг (`[6]`, `Tank`)**:
   * Отображается ярко-красным контуром увеличенного размера ($1.5\times$) с бейджем `Tank#X`.
   * На миникарте отображается крупной красной точкой.
3. **Дуэлянт (`[7]`, `Duelist`)**:
   * Отображается фиолетовым неоновым контуром с бейджем `Duel#X`.
   * На миникарте отображается фиолетовой точкой.

### Быстрое изменение архетипа:
Если кликнуть ЛКМ выбранным инструментом врага по уже существующему спавну другого типа, его архетип мгновенно перезаписывается (например, клик `[6]` по обычному врагу превращает его в Танка).

### Удаление спавна:
Клик **ПКМ** по тайлу спавна врага мгновенно удаляет его из списка.

## 3. Настраиваемые двери перехода (Door Blocks)

Двери в игре представляют собой интерактивные блоки тайла `3`:
* При выборе инструмента Двери `[3]` на верхней и нижней панелях активируются цифровые кнопки выбора целевой комнаты (1 .. 10).
* Клик ЛКМ по тайлу размещает дверь с меткой `-> Rm X`.
* Клик ПКМ по существующей двери циклически переключает ее целевую комнату без необходимости пересоздания блока.
* **Исключение фантомных дверей**: В игре отсутствуют любые автоматически сгенерированные или жестко зашитые двери на краях комнат. Переход срабатывает **исключительно** на блоках дверей, явно расставленных в редакторе карт.

## 4. Форматы хранения комнат и синхронизация

При сохранении (`Ctrl+S` или `F7`) движок автоматически сохраняет карту комнаты в три взаимосвязанных формата:
1. **`.kv` (KeyValues координатный конфиг, например `assets/maps/room_1.kv`)**:
   * Содержит габариты комнаты (`width`, `height`), спавн игрока, спавны всех врагов с их типами (`0`, `1`, `2`), координаты дверей и длины платформ.
   ```kv
   "Enemies"
   {
       "enemy_0"  "12 5 0"
       "enemy_1"  "43 7 1"
       "enemy_2"  "35 14 2"
   }
   ```
2. **`.txt` (ASCII сетка, например `assets/maps/room_1.txt`)**:
   * Текстовая матрица символов (`#` — стена, `=` — платформа, `D` — дверь, `P` — игрок, `E`/`T`/`U` — спавны врагов).
3. **`.png` (Цветовая пиксельная карта, например `assets/maps/room_1.png`)**:
   * Каждый пиксель соответствует тайлу:
     * Синий (`#0080FF`) — Игрок.
     * Серый (`#B4B4B4`) — Обычный враг.
     * Красный (`#FF1E1E`) — Жирный враг (Tank).
     * Фиолетовый (`#AA46E6`) — Дуэлянт (Duelist).
     * Бирюзовый (`#00E5FF`) — Дверь.
     * Черный (`#000000`) — Стена.
     * Зеленый (`#4CAF50`) — Платформа.
     * Белый (`#FFFFFF`) — Воздух.
